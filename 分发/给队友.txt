《8时46分》v2.1 内测说明
====================================

■ 用什么浏览器打开
不用 Chrome 也不用 Safari，随便一个都行：
  电脑：Edge 完全没问题（Edge 和 Chrome 是同一个内核）
  手机：Edge / 夸克 / QQ浏览器 / UC / 百度浏览器 / 手机自带浏览器 —— 都能跑

唯一要避开的一个坑：
  浏览器的「兼容模式」「IE 模式」「极速模式关掉」—— 开了会白屏或卡死。
  看到地址栏写着"兼容"两个字，就切回普通/极速模式。

微信、QQ 的聊天框里点 html 会拦下来，先"下载"，再用「其他应用打开」→ 选浏览器。
最省事的方式其实是别人给你一个网址，直接在浏览器地址栏输进去（找我要链接）。

■ 三秒自检（打开后看这三条）
  1. 顶部时钟在跳：9时46分 → 9时47分……        → 画面正常
  2. 按住屏幕拖一下，双塔跟着动                    → 操控正常
  3. 故意撞一次飞机，1.5 秒后弹出结算卡             → 脚本正常
三条都过，你的浏览器就没问题，可以开始测了。
哪条不对，把浏览器名字告诉我，我针对性处理。

■ 怎么玩
拖动屏幕任意位置（左下角有虚拟摇杆；电脑能用 WASD / 方向键）。
你操纵的是世贸双塔，从四面八方飞来的客机会撞上来。躲开的每一秒，游戏内时间往前走一分钟。
撞上就结束，出一张结算卡。

■ 这一版和上一版的区别
1. 底图换成真实的纽约航拍
2. 双塔模型换成手绘版
3. 开局双塔站在原照片里双塔的位置
4. 判定范围只算塔身实心部分，塔周围透明的地方不再算碰
5. 双塔缩到原来一半大小（上一版太大，躲不开）
6. 加了老浏览器兜底：Path2D / padStart / closest / Math.hypot 缺失时自动降级，
   没有 Pointer 事件的浏览器改用 touch 事件，摇杆照样能用

====================================
【A】负责找 bug 的同学：请重点测这几条
====================================
1. 贴着塔身外侧擦过去（差几像素那种）—— 应该不死。这是这一版的主要改动，重点验
2. 把塔推到屏幕四个边角 —— 会不会卡住、能不能把塔推出画面外
3. 快速来回反向拖 —— 松手后应该立刻停，不能有滑行/惯性
4. 手机横竖屏切换一次再切回来 —— 画面有没有错位、摇杆位置对不对
5. 连续玩到 3 分钟以上（游戏内约 11 点）—— 飞机变多时会不会掉帧、卡顿
6. 故意撞不同的位置 —— 结算卡写的是不是"撞北塔说北塔、撞南塔说南塔"（故意不按真实历史顺序，属正常）
7. 结束 → 再来一次 → 连开三局 —— 时间、飞机、背景有没有残留上一局的痕迹

反馈按这 6 项写，缺一项就没法复现：
  设备+浏览器 | 怎么操作的 | 你期望发生什么 | 实际发生什么 | 能不能稳定重现 | 截图或录屏

====================================
【B】负责评估好玩程度的同学：先别往下看，直接玩 3 局
====================================
玩完再回答：
1. 第一局活了多久？大概第几局开始觉得紧张？
2. 你觉得躲是靠"技术"还是靠"运气"？
3. 塔的大小合不合适？想更大还是更小？
4. 同屏飞机数量：太少 / 正好 / 太多？
5. 有没有哪一次你觉得自己死得莫名其妙、不知道为什么碰到？
6. 如果只能改一件事，你改什么？
7. 一句话：你会不会主动想再玩一局？
