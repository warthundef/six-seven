怎么把这个游戏放到网上（做成台风那种网址）
================================================

台风那个网址 https://lovewcycle.com/games/others/typhoon-escape.html
拆开看是三样东西拼起来的，我们缺的只是前两样：

  1. 一个域名            lovewcycle.com            （每年几十块，或者用免费平台送的域名）
  2. 一台能放静态文件的托管  把 html 传上去就行          （免费平台很多）
  3. 一个 html 文件         typhoon-escape.html        （我们已经有了 index.html）

静态网页不需要服务器程序、不需要数据库，就是"把文件放上去，任何设备访问就下载它"。
所以这件事比装个 App 简单得多。

================================================
方式一：GitHub Pages —— 免费、永久、不用实名（推荐）
================================================
注册一次账号，之后每次更新只要网页上替换一个文件。

1. 打开 https://github.com 注册（邮箱即可，不用实名、不用信用卡）
2. 右上角 + → New repository
   仓库名随便填，比如 eight-forty-six
   选 Public（免费账号的 Pages 只能公开仓库）
   点 Create repository
3. 进仓库 → Add file → Upload files → 把 分发\index.html 拖进去 → Commit changes
4. 仓库上方 Settings → 左侧 Pages
   Source 选 "Deploy from a branch"
   Branch 选 main，目录选 / (root) → Save
5. 等 1~2 分钟，页面顶部会出现网址：
      https://你的用户名.github.io/eight-forty-six/
   这个网址手机、电脑、任何地方都能打开，永久有效，不用你开机。

以后更新：仓库里点 index.html → 右上角铅笔/上传新文件覆盖 → 1 分钟后网址刷新即新版。
网址永远不变。

注意：
- 国内访问 github.io 大部分地区正常，偶尔慢或间歇性打不开，属于正常波动
- 仓库必须是 Public
- 文件名必须是 index.html 放在根目录

================================================
方式二：Netlify —— 拖一下就好，但要注册一次
================================================
1. https://app.netlify.com/drop
2. 登录/注册一次（GitHub 账号可直接授权）
3. 把整个「分发」文件夹拖进虚线框
4. 得到 https://随机名.netlify.app
5. 之后更新：进这个站 → Deploys → 再拖一次文件夹 → 网址不变

重要：登录只有第一次。之后浏览器会记住，不用每次登。
如果你每次都被要求登录，八成是无痕窗口 / 清过 cookie / 换了浏览器。

================================================
方式三：自己的域名（最像台风那种，要花钱）
================================================
1. 买域名：阿里云 / 腾讯云 / Cloudflare，.com 大约 50-80 元/年
2. 托管还是用 Netlify 或 Cloudflare Pages（免费），把域名解析过去
3. 最后得到 https://你的域名/games/xxx.html 这种地址

注意：域名绑国内服务器需要 ICP 备案（要身份证+等 1-3 周）；
      绑 Netlify / Cloudflare 的海外节点不需要备案，但国内访问速度看运气。
现阶段不建议花这个钱，等游戏定型了再说。

================================================
附：手机打不开局域网 http://10.x.x.x:8000 的原因
================================================
按可能性从高到低排：

1. 手机根本没连同一个 WiFi
   用 4G/5G 流量是绝对打不开的。让手机连上电脑所在的同一个 WiFi。

2. 这个 WiFi 开了「客户端隔离 / AP 隔离」
   酒店、学校、公司网络常见，设备之间互相看不见。
   换一个手机热点试：电脑连手机热点，手机自己用同一热点，通常能通。

3. Windows 防火墙拦了
   第一次运行 bat 会弹"Windows 安全警报"，必须点「允许访问」并勾上「专用网络」。
   如果当时点了取消：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙
   → 找到 Python → 勾上「专用」和「公用」。

4. 用微信内置浏览器打开了
   微信会拦 http:// 局域网地址。必须用系统浏览器（Safari / Chrome / Edge）输网址。

5. 网址输错
   是 http:// 不是 https://，冒号是英文冒号，端口 8000 不能漏。

结论：局域网这条路适合三个人现场在一起时用。
      要「手机随时随地都能打开」，只有方式一或方式二能做到。
